# Technologieauswahl

Für unsere **REAP-App** verwenden wir folgende Technologien:

-   **Flutter** für die App
-   **Dart** als Programmiersprache für Flutter
-   **Java mit Spring Boot** für das Backend
-   **H2** als Datenbank
-   **REST API** für die Verbindung zwischen App und Backend

## Warum diese Technologien?

Wir verwenden **Flutter**, weil wir damit eine mobile App entwickeln
können.

Für das Backend verwenden wir **Java und Spring Boot**, da wir Java
bereits aus dem Unterricht kennen.

Die **H2-Datenbank** verwenden wir zum Speichern von Daten, zum Beispiel
Restaurants, Reservierungen und Bestellungen.

Über eine **REST API** kann die Flutter-App mit dem Java-Backend
kommunizieren.

## Einfacher Aufbau

Flutter App → REST API → Java / Spring Boot → H2-Datenbank
